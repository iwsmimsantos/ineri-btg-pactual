# Nome do Projeto: INERI

## Nome do Grupo: INERI


Esta documentação está organizada em diferentes arquivos conforme apresentado abaixo.

### Gestão do Projeto

- **[Gestão do Projeto](GestaoProjeto.md)**: Este documento tem como objetivo acompanhar e mapear o desenvolvimento do projeto ao longo de todas as sprints, identificando oportunidades de melhoria e pontos a serem implementados.

### Processo de Desenvolvimento de Software

- **[Gestão de Configuração](GestaoConfiguracao.md)**: Este documento estabelece diretrizes claras para a utilização de boas práticas no desenvolvimento de software, visando a organização e a qualidade do código. Todos os membros da equipe devem seguir as instruções definidas. 
- **[Guia de Padrões de Desenvolvimento](GuiaPadroesDesenvolvimento.md)**: Este documento apresenta estabelecer padrões de codificação e práticas de desenvolvimento para garantir a qualidade e a consistência do código.

### Desenvolvimento do Produto

- **[Projeto](Projeto.md)**: Este documento foi elaborado com o objetivo de servir como um guia completo para o leitor, fornecendo uma visão ampla de todas as etapas e aspectos do projeto. Nele, são apresentadas desde a descrição do parceiro envolvido e o problema proposto, até as decisões estratégicas tomadas, as análises de negócios realizadas e a documentação técnica relacionada ao código desenvolvido.
- **[Manual de Instalação](Manual-Instalacao.md)**: Este manual tem como objetivo orientar o usuário na instalação e configuração do ambiente necessário para executar o projeto INERI localmente.
